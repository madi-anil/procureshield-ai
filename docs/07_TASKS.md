## 2. Universal Definition of Done 

Every module task (`TASK-04` through `TASK-13`) is marked **DONE** only when all criteria below are satisfied:

1. **Business Logic & Validation:** Functional requirements implemented with Jakarta `@Valid` DTOs and `@RestControllerAdvice` error handling[cite: 17].
2. **Contract Compliance:** Endpoint URLs, HTTP methods, status codes, and JSON payloads match `docs/05_API_CONTRACT.md` without drift[cite: 11].
3. **Security & RBAC:** `@PreAuthorize` role checks verified against unauthorized (`401`) and forbidden (`403`) access attempts.
4. **Automated Tests:** JUnit 5 + Mockito unit tests written and passing locally (`mvn test`) with >= 80% service-layer line coverage[cite: 17].
5. **Documentation & Git Hygiene:** Swagger `@Operation` annotations added, docs updated if behavior changed, and code pushed to a feature branch with a Pull Request into `develop`[cite: 15, 16, 17].
